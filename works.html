Incan - Pythonic Language That Compiles to Rust

Description

Incan is a statically typed programming language for writing clear, high-level application code that compiles to native Rust. It keeps Python-like readability while making types, errors and mutability explicit. Built by Encero Systems and currently in active development (beta).

Organisation

Encero Systems

Technologies
Rust Compiler Programming Language Open Source
Key Features
  • Python-like, readable syntax
  • Compiles to native Rust binaries
  • Explicit error handling with Result and Option
  • Strong domain types with newtype and model
  • Rust interop for crates and performance work
  • Built-in tooling: formatter, test runner and LSP
